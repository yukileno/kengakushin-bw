# 思考力育成ブロックワールド

愛媛県学力診断調査（県学診）の練習問題を解くと、**1問正解ごとにブロックワールドのブロック学習の時間がふえる**（算数15秒・国語5秒・社会5秒・資料の読み取り20秒・全国学力テストへの道は大問1題の完成で60秒。ただし同じ大問は1回目だけで、2回目以降は10秒）アプリです（素材もいっしょにもらえます）。
ためておける時間は最大3分。時間がゼロになると、自動で問題画面が出ます。`T` キーでいつでも問題を解けます。
視点の速さは、一時停止メニュー（Esc）のスライダー、または遊んでいる間の `[` `]` キーで変えられます（キーボードモードのみ、初期値1.8倍）。
キーボード操作（Chromebook向け）: `M` ＝こわす・たたかう（ポンとおすだけで1つ壊れる。おしつづけるとどんどん壊す）、`N` ＝置く・つかう・食べる（マウスのクリックでもOK）。

- `index.html` … ゲーム本体（[BlockWorld2](https://github.com/yukileno/BlockWorld2) をもとにしたサバイバル型ブロックゲーム）
- `quiz/` … 県学診の問題画面（ゲームの上に重ねて出る）。**問題データの本体はここ**（`quiz/data/`。国語の読解は `yomi.js`、社会の資料から答える問題は `shakai2.js`）。問題を足す・直すときは、ここだけを直す
  - [kengakushin-practice](https://github.com/yukileno/kengakushin-practice) は旧版（クイズだけのアプリ）。もう更新しない
  - `quiz/data/` … 算数・社会・国語・資料の読み取り・全国学力テストへの道の問題データ
- 達成率・ドット絵・ロックはありません（ごほうびは「ブロック学習の時間」だけ）

## 教科を増やすとき（1教科ずつ公開）

`quiz/index.html` の `const ENABLED = ['算数'];` に教科名（算数・社会・国語・しりょう・じっくり）を足して公開します。
ローカルでは `quiz/index.html?s=all` のように開くと、公開前の教科も試せます。

## 先生用（記録・設定）

`quiz/index.html#teacher` を開きます（正答率・まちがえた問題・CSV保存）。記録はこの端末のブラウザの中だけに保存され、外には送りません。

### 先生モード（問題の確認用）

先生用メニューの一番上の「先生モード」を **オン** にすると、次のようになります（設定はこの端末のブラウザだけに保存。初期はオフ）。

- 問題画面（と「全国学力テストへの道」）に **「スキップ（先生用）」ボタン** が出る（画面の**右下に固定**。どの問題でも同じ位置）。スキップした問題は、正誤・まちがい直し・ごほうびのどれにも記録されない。
- 公開前の教科（社会・国語・資料の読み取り・全国学力テストへの道）も、教科えらびに ぜんぶ出る（`ENABLED` に関係なく）。
- 教科えらびの画面に「先生モード中」と出る。「オフにする」から、先生用メニューに戻れる。

ゲーム本体と同じ端末・同じブラウザなら、ゲームの中から開く問題画面にも反映されます。児童の端末では、オフのままにしてください。

## 問題の形式

検索練習（答えを自分で思い出して入力する）の効果をねらい、**選択式はできるだけ避けて、数字・ことば・本文からのぬき出しを入力する形式**にしています。選択式が残っているのは、国語の「漢字の書き・送りがな」と「同訓異字・同音異義語」だけです（入力すると、端末の変換候補に答えが出てしまうため）。「資料の読み取り」と「全国学力テストへの道」も、資料から読み取った数字やことばを入力する形式です。

## ベッド（夜をこす）

- 作り方：羊毛3＋木材3（作業台）、または、木材6（作業台）。
- 置いたベッドにさわる（クリック／Nキー）と、そこが**リスポーン地点**になる。
- **夜**にさわると、ぐっすり ねて朝になる（体力も全回復。夜の敵はいなくなる）。昼は ねむれない。近くに敵がいるときも ねむれない。

## 先生用コマンド（フリーモードだけ）

`#teacher` で「フリーで建築」を始めたとき、`/` キー（または Enter）で入力欄が開きます。Enter で実行、Esc で閉じます。
**gunpro で全チームマスター（11チーム）の人**は、ふだんのサバイバルでも使えます（初めて使えるとき、画面にお知らせが出ます）。

| コマンド | 内容 |
|---|---|
| `/time day\|noon\|sunset\|night\|midnight\|0〜23999` | 時間を変える |
| `/tp x y z`、`/tp x z`、`/tp spawn` | テレポート（`~` で今の位置から。例 `/tp ~ ~10 ~`） |
| `/weather clear\|rain` | 天気 |
| `/give アイテム名 [数]` | アイテム（英語名・日本語名どちらでも。例 `/give diamond 10`） |
| `/heal`、`/clear`、`/pos`、`/help` | 回復／敵を消す／今の場所／一覧 |
